# LeetCode DSA Solutions

This repository contains my **LeetCode Data Structures and Algorithms practice**, with solutions written in **Java**.

The purpose of this repository is to consistently practice problem-solving, understand different DSA patterns, and improve my ability to write efficient and clean solutions.

## 🎯 Motto

> **Solve. Understand. Improve. Repeat.**

I don't want to just solve problems.
For every problem, the goal is to understand:

* What is the problem asking?
* What pattern can be used?
* Why does the approach work?
* Can it be optimized?
* What are the time and space complexities?

## 📂 Repository Structure

Each LeetCode problem is stored in a separate folder.

```text
LeetCode/
│
├── <problem-number>-<problem-name>/
│   ├── Solution.java
│   └── README.md
│
├── <problem-number>-<problem-name>/
│   ├── Solution.java
│   └── README.md
│
└── README.md
```

### `Solution.java`

Contains the Java solution for the problem.

### `README.md`

Contains the explanation of the solution, including:

* Problem understanding
* Approach
* Step-by-step explanation
* Example / test case
* Time complexity
* Space complexity
